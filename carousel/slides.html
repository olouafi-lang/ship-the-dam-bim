01 · AUDIT MY OLD PROJECT

I asked it to run our old code and read the output.

Last winter we built a model checker in a weekend. It had a button that fixed your file.

Claude opened the fixed file. Our tool had labelled a living room and an entry hall as “Office”, because that was first on the list of allowed values.

The readiness score went up.

03 · READ ONE INTERVIEW

I asked an engineer about language problems.

They told me about software versions instead.

  • A
    One team, one model, two versions of an export plug-in. The client spotted the difference.
  • B
    A supplier’s old software could not open the file. Ten variants sent before one worked.

About a week each. Both found by the person receiving.

WHAT I AM KEEPING

Three rules from the week.

  • 1
    Ask about the last time it went wrong before choosing the problem.

    Open every file your tool produces and read it.
  • 3
    A tool that edits needs a higher bar than a tool that reports.
